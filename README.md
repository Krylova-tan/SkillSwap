# SkillSwap

## 📌 Описание проекта

Это современный веб-проект на [React/TypeScript], предназначенный для обмена навыками «Я научу / Хочу научиться»

## 🛠 Технологии

- Frontend: React 18, TypeScript, Vite, CSS-modules
- Линтинг: ESLint (+ Airbnb), Prettier, Stylelint

## ✨ Реализованная функциональность

- Интерактивные карточки навыков
- Динамическая цветовая схема по категориям
- Логика лайков и счетчиков
- Разворачивающиеся дополнительные навыки
- Бесконечный скролл с лоадером
- Адаптивная сетка карточек
- Настройка редиректов

## 🚀 Запуск проекта

Клонируйте репозиторий (ветку develop)

```
git clone https://github.com/PM-YandexPracticum/SkillSwap_30_3
cd ваш-проект
```

Установите зависимости

```
npm install
```

Запуск проекта

```
npm run dev
```

Production сборка

```
npm run build
```

Проверка стиля кода

```
npm run lint
```

Автоисправление ошибок

```
npm run lint:fix
```

Форматирование кода

```
npm run format
```
